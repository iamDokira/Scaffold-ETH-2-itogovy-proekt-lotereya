# ЛУТКА-МУТКА — Лотерея 6 из 49

**ЛУТКА-МУТКА** — децентрализованная лотерея на блокчейне Ethereum. Игрок покупает билет стоимостью 1 ETH, выбирает 6 чисел от 1 до 49 и ожидает розыгрыша.

## Возможности

- Покупка лотерейных билетов за ETH.
- Выбор 6 уникальных чисел от 1 до 49.
- Проведение розыгрыша владельцем контракта.
- Автоматическое начисление призов в зависимости от количества совпадений.
- Просмотр своих билетов и истории розыгрышей.
- Подключение криптовалютного кошелька MetaMask.

## Требования

Перед запуском установите:

- [Node.js](https://nodejs.org/) версии 22.13.0 или выше.
- [Yarn](https://yarnpkg.com/).
- [Git](https://git-scm.com/).

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/iamDokira/Scaffold-ETH-2-itogovy-proekt-lotereya.git
```

Перейдите в папку проекта:

```bash
cd Scaffold-ETH-2-itogovy-proekt-lotereya
```

Установите зависимости:

```bash
yarn install
```

## Запуск проекта

Для локального запуска откройте три отдельных терминала в корневой папке проекта.

**1. Запуск локального блокчейна Hardhat**

```bash
yarn chain
```

**2. Развёртывание смарт-контракта**

```bash
yarn deploy
```

**3. Запуск веб-приложения**

```bash
yarn start
```

После запуска приложение будет доступно по адресу:

http://localhost:3000

## Подключение MetaMask

Для работы с локальным блокчейном добавьте в MetaMask сеть Hardhat:

- Название сети: Hardhat
- RPC URL: `http://127.0.0.1:8545`
- Chain ID: `31337`
- Валюта: ETH

Для тестирования используйте локальные тестовые аккаунты Hardhat. Не используйте их в основной сети Ethereum.

## Тестирование

Запуск тестов смарт-контракта:

```bash
yarn test
```

Проверка типов Solidity-проекта:

```bash
yarn hardhat:check-types
```

Проверка типов Next.js:

```bash
yarn next:check-types
```
